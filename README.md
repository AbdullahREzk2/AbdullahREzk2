## 🚀 Featured Projects

### 🗳️ SurveyBasket — Online Survey Management System
> A production-ready polling platform with a strong emphasis on clean architecture and real-world business logic.

**Highlights:**
- 3-Layer Architecture (API / BLL / DAL)
- JWT Authentication + Refresh Tokens + Role & Permission System
- Poll, Question & Voting management with business rules
- Background job processing with **Hangfire**
- Profile image upload via **Cloudinary**
- Structured logging with **Serilog**
- Health checks & IP-based rate limiting
- Deployed on **ASPMonster**

[![Repo](https://img.shields.io/badge/Repository-181717?style=for-the-badge&logo=github)](https://github.com/AbdullahREzk2/Survey-Basket)
